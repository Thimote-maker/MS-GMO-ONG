GMO — Frontend professionnel

Fichiers : index.html, studio.html, dashboard.html, css/style.css, js/app.js, js/dashboard.js et assets.

Le tableau de bord est un prototype frontend : les activités sont enregistrées dans le localStorage du navigateur. Pour une vraie publication WordPress avec comptes responsables, base de données, upload d'images et calendrier partagé, connecter ce design à WordPress via un thème/plugin.

Pour tester : ouvrir index.html ou utiliser Live Server dans VS Code.
Pour héberger : envoyer tout le contenu du dossier dans public_html/htdocs chez votre hébergeur.
